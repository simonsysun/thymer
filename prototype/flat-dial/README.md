# 平面表盘交互预览

> 当前交互以 `prototype/flat-dial/cycle-design.md` 为准：Work 保持 Rest 时长并携带外杆移动；Cycle 在零 Rest 时可回推 Work；两段均可为零，中央保留双读数。下方历史迭代规则已被替代。

本地 HTML/SVG 组件样机，用于准确调整圆盘层次、径向直线拨杆、中央按钮和动效。正式产品仍为 Mac 原生应用；这里不修改、构建或启动 SwiftUI 预览。

在项目根目录运行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory prototype/flat-dial
```

打开 <http://127.0.0.1:8765>。零依赖、无外部资源、无持久记录。退出服务按 Ctrl-C。

## 这轮要看什么

- 两个轻薄圆形层面，而不是厚实进度描边或金属表盘。
- 一长一短两根 2 px 径向直线，末端是 8 / 7 px 小圆球；杆身和端部均可拖动。
- 中央按钮默认直径 102 pt；玻璃感只保留轻微边缘与背景模糊，左侧滑块可比较。
- 保留播放／暂停、少量必要的读数、任务一行、Reset 和少量菜单设置。
- 工作与暂停时仍可改时长；当前阶段不得设置为已过时间之前，暂停调整后仍暂停。

左侧所有控件只属于预览环境。工作／休息预览按钮注入示例进度，不把跳过的时间加入累计；60 倍速累计仅为演示。

HTML 的玻璃是近似效果，不能据此判断 Apple Liquid Glass 的精确折射表现。正式记录持久化、任务账本、系统通知、休眠和跨日处理不在这个组件试验中。

本轮最新用户反馈优先于根目录旧设计文档：整体更平面，避免银色／透明材质的照片质感；保留两个圆形层次、细长短直线拨杆、较大且分层清楚的中央玻璃按钮。先用这个组件确认，再将选定参数适配到 SwiftUI。

## 9 月 7 日第二轮反馈

- 工作为蓝灰，休息为薄荷绿；整个休息区保持可见，经过的部分再加深。色块的起点与工作杆共用角度，终点与休息杆共用角度，跨 12 点也一致。
- 移除 120 / 30 分钟上限。每圈仍为 60 分钟，可以连续拖到 3、4 小时或更长。完整圈数用逐层加深的底色表示，多圈阴影在表盘外平滑扩散；不会无限增大组件。精确时长在中央读数确认。
- 拖动时中央播放图标暂时变成 Work / Rest 和设定时长；松开、取消拖动或窗口失焦后立即恢复。悬停不弹浮层。键盘调整时按下显示、松开恢复。
- 运行／暂停修改仍保留已用时间与累计；休息中调整工作杆只修改下轮工作时长。

逻辑与几何检查：`node prototype/flat-dial/check.mjs`。本轮按用户偏好不接管浏览器，最终视觉与手感由用户刷新预览后确认。

## 比例与玻璃对照迭代

- 外盘半径 134、内盘约 105.3、中央按钮直径 102。保持原有大小关系，以内盘／外盘面积约 0.618 作微调。
- 剩余工作区提高对比，工作／休息色块改为共享固定光照位置的径向渐变。多圈叠加仍保留明暗，不变为均匀实色。
- 新增“单段最长 2 小时”，默认开启，工作和休息分别限制。关掉可超过两小时；重新开启不会截短已经开始的超长阶段，当前阶段不能再加长，后续阶段应用上限。
- 左侧时长对照选择器注入静态样本；选 3／4 小时会显式关闭该样本的限制。它是预览工具，不属于产品面板。
- 独立 [SwiftUI 材质对照](../glass-study/README.md) 展示实际系统 Liquid Glass；HTML 中仍是 CSS 近似效果。

本轮检查：时长上限、关闭上限、运行中开启上限不截断、跨阶段恢复限制、最小一分钟与现有计时／几何检查通过；实际截看 1、60、120、180、240 分钟，浏览器无脚本错误。没有接管用户正在操作的预览标签页。

## 拖动范围与边界接回

拖动从杆身或端部开始，按住后可以移到表盘外继续操作，没有外半径上限。中央按钮以内是无效区，不更新时长；移回外围后按有效鼠标方向继续。中央无效区随按钮尺寸变化。

拨杆到达上下限后暂时脱开，鼠标反转不会立即带动拨杆。必须回到或扫过该拨杆的径向方向才重新接上；额外绕圈不积累需要逐圈偿还的角度。休息杆按工作结束角度作偏移，使用相同规则。松手、取消或丢失捕获会结束本次拖动。

回归检查：`node prototype/flat-dial/drag-check.mjs`。覆盖圆心内移动、远距离操作、上下限接回、额外绕圈、休息杆偏移及运行中下限变化。两条原有错误轨迹已复现，并用新逻辑验证通过；实际细微手感仍由用户试用确认。

## 最新联动规则：休息终点保持不动

这条规则替代早期“移动工作杆始终保持休息时长”的方案。移动工作杆时，先保持累计休息终点不变：工作加长，休息缩短；工作缩短，休息加长。只有间隔缩至一分钟后，工作杆才推着休息终点向前。推过后退回工作杆，休息终点留在新位置，不自动退回。多圈按累计分钟处理。

两小时限制开启时，如果后退工作杆会让休息超过两小时，则工作杆也会停在相应边界，并沿用鼠标对齐后接回的规则。已开始的休息保留本轮计时总长度；移动工作杆改变下一轮设定，不改已经记下的时间或当前休息倒计时。显式调整休息杆仍可调整当前休息总长度。

检查：`node prototype/flat-dial/linkage-check.mjs`，覆盖固定终点、最小间隔推动、反向释放、多圈、时长上限和本轮计时不受改工作设定影响。

## 连续拖动与轻量触感（最新，替代中央无效区）

取消中央按钮大小的无效区。抓住拨杆后可以进入按钮范围继续转动；仅在圆心附近 32 px 内连续降低角度灵敏度，半径接近零时逐渐趋稳。不是硬开关，也不是扩大一块不可操作区域。恰好圆心没有有效方向，仅该奇点保留原值。两小时边界仍要求方向对齐再接回。

显示角度跟随连续值，计时设定仍按整分钟。HTML 松手后用很短的收束将图形归到整分钟；不为拖动添加惯性或滞后。球形端点悬停／抓取时轻微放大并显出局部光晕，中央按钮有轻微受力反馈；减少动态效果设置会关闭这些过渡。

默认不画刻度。左侧“表盘参考”可改为四个方向的淡径向线，延伸穿过工作与休息区域，配 0 / 15 / 30 / 45 分钟。仅属于比较选项。

参考与搜索关键词：
- Fluid Interfaces / Direct Manipulation：[Apple Motion](https://developer.apple.com/design/human-interface-guidelines/motion)、[Designing Fluid Interfaces](https://developer.apple.com/videos/play/wwdc2018/803/)。重点看操作与反馈的直接联系，不复制旧页面外观。
- Material 3 Expressive motion / spring microinteractions：[Material Design](https://m3.material.io/)。参考有阻尼的响应与收束，不照搬其色彩和整套组件。
- Tactile minimal UI / subtle depth：[Linear design refresh](https://linear.app/now/behind-the-latest-design-refresh)。参考克制的层级。

检查更新：JS 与 Swift 轨迹验证按钮范围内正常响应、近心连续阻尼、远距离操作、边界接回、固定休息终点；浏览器确认无刻度和径向参考线布局、50→55 分钟时休息终点不变、无脚本错误。实际触感继续由用户试用决定。

## 最新布局：外侧 Cycle，内侧 Work

外侧长杆现在是整轮结束端点，中央拖动读数显示 Cycle 总时长；内侧短杆是 Work 工作结束端点。两者之间是 Rest。颜色仍保持 Work 蓝灰、Rest/Cycle 薄荷绿；扇区半径随角色交换。表盘下方常驻 Work / Rest / Cycle 三项设定时长，任务行仍在其下。

外杆移动保持 Work 不变，改变 Cycle 与 Rest；内杆移动保持 Cycle 终点，休息不足一分钟时推动 Cycle。两小时开关仍限制单段，Cycle 可以是两段之和。内部 rest 字段继续存休息长度，Cycle 是它与 Work 的和。

设计依据见 [cycle-design.md](cycle-design.md)。逻辑检查新增整轮读数、外杆调整、最小休息与单段上限；浏览器确认 60→65 分钟时 Work 50 保持、Rest 10→15，深浅色常驻时长行无溢出，未发现脚本错误。

## 外杆回推与稳定时长列（最新）

外杆普通拖动时中央显示 Rest（Cycle 减 Work）。休息达到最小间隔后继续往回，会推动内侧工作端点一起缩短；回推过程中中央显示 Work，外杆暂时采用 Work 颜色。重新向外拖则只加长休息并恢复 Rest 显示与绿色。两杆始终保留间隔；运行中还受已用时间下限约束，不能改掉已经记下的时间。

时长区采用三个固定等宽列，12 px 标签在上、15 px 等宽数值在下；数字变长不移动标签。浏览器检查 60→55→50 的外杆回推，得到 Work 49 / Rest 1 / Cycle 50，三个标签横坐标保持不变。Swift 与 JS 联动检查均覆盖外杆回推和向外释放。

## 前沿亮弧试验已撤回

按用户反馈移除亮弧、羽化色带及预览对比开关，进度仅由扇区颜色变化表达。保留浅色已用区减淡、原蓝灰和暖灰配色对照，拨杆联动与计时逻辑不变。

## 任务行编辑试验

聚焦名称时，右侧今日累计替换为同一行的 Continue / New。Enter 默认 Continue，Esc 或点到行外取消，中文输入法确认不提交。空白名称不可提交，同名可 New；确认后恢复累计。样机在内存中区分沿用名称组与新建名称组，计时不重置。尚未连接数据库或实现持久化时间片；刷新会丢失这些试验数据。

## 今日时间线卡片

左上角日历按钮打开同宽单日卡片，260 ms 水平滑入，返回按钮或 Esc 收回；支持减少动态效果，后台计时不因浏览记录而暂停。内部滚动展示 00:00–24:00 的只读时间轴，初始定位首段记录；蓝灰工作、绿色休息，显示任务、时间和时长。Continue / New 使用同等按钮样式。

当前只用于设计评审：卡片明确标记“示例记录”，与今日真实累计分开；左侧关闭示例可看空状态。尚未连接数据库，不把示例加入任务累计。参考用户 Apple Calendar 截图的单日网格与彩色事件块，以及 Apple Motion 的简短反馈和可打断过渡。

日历紧凑迭代：休息统一显示“休息”，不提供休息内容编辑。移除底部说明栏。首次打开保留日期与总计，向后滚动 72 px 内连续收起副标题及总计、缩小日期，向回滚动回到起始浏览位置时展开；不新增滚动惯性。抽卡改为 320 ms 水平位移与短淡入，减少动态效果仍禁用转场。

日历密度：右上角 − / + 在每分钟 0.75–5 px 间缩放，按钮以视野中央为锚点，触控板以手势位置为锚点（Chromium Ctrl-wheel / Safari gesture）。普通双指滚动仍只浏览时间线；短记录随密度收起详情，极短条保留悬停完整信息。缩放动画不改变记录起止时间。返回按钮与入口同位于左上角，鼠标与键盘焦点样式分开；键盘仍有可见焦点。浏览器按钮缩放检查保持中央时间点，实际触控板捏合手感待用户确认。

当前 HTML 页面语言为 en-US，包含控件、通知、无障碍名称和示例任务。日历日期采用 `Sep 7 · Mon`，日历时间使用 12 小时制 AM/PM；倒计时仍表示时长。用户输入的任务文字不会被翻译。

日历转场改为 260 ms 不透明卡片水平滑入，表盘轻退 14 px；独立裁切层保留弹窗顶部箭头，避免卡片越界与文字交叠。CSS 转场可中途反向，Esc 可立即返回，减少动态效果时直接切换。

转场无动画的根因：检查浏览器发现 `prefers-reduced-motion: reduce` 为 true，原规则使计算后的 transition 为 none。新增默认开启的 Preview transitions，仅在设计样机中明确覆盖两个页面的转场；关闭后重新遵循系统偏好，不改系统设置。已捕获打开和返回过程中的非终点 transform，计算时长为 0.26s。

转场方向按最新反馈改为日历从左侧进入、向左侧收回，表盘向右轻退；时长与缓动不变。

## Settings card

The ellipsis opens a right-entry settings card; its upper-right return control slides it back out. Timer settings retain Sound, Auto-start next cycle, and the per-phase two-hour limit. Appearance contains System / Light / Dark (System by default, updates with the browser preference) and Blue gray / Warm gray work color. Changes apply immediately in the disposable preview and are not persisted. Center button size and glass strength remain preview-only design controls, not MVP settings. No extra phase-confirmation feature is included.
