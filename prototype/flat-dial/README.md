# 平面表盘交互预览

本地 HTML/SVG 组件样机，用于准确调整圆盘层次、径向直线拨杆、中央按钮和动效。正式产品仍为 Mac 原生应用；这里不修改、构建或启动 SwiftUI 预览。

在项目根目录运行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory prototype/flat-dial
```

打开 <http://127.0.0.1:8765>。零依赖、无外部资源、无持久记录。退出服务按 Ctrl-C。

## 这轮要看什么

- 两个轻薄圆形层面，而不是厚实进度描边或金属表盘。
- 一长一短两根 2 px 径向直线，末端是 8 / 7 px 小圆球；杆身和端部均可拖动。
- 中央按钮默认直径 100 pt；玻璃感只保留轻微边缘与背景模糊，左侧滑块可比较。
- 保留播放／暂停、少量必要的读数、任务一行、Reset 和两个菜单设置。
- 工作与暂停时仍可改时长；当前阶段不得设置为已过时间之前，暂停调整后仍暂停。

左侧所有控件只属于预览环境。工作／休息预览按钮注入示例进度，不把跳过的时间加入累计；60 倍速累计仅为演示。

HTML 的玻璃是近似效果，不能据此判断 Apple Liquid Glass 的精确折射表现。正式记录持久化、任务账本、系统通知、休眠和跨日处理不在这个组件试验中。

本轮最新用户反馈优先于根目录旧设计文档：整体更平面，避免银色／透明材质的照片质感；保留两个圆形层次、细长短直线拨杆、较大且分层清楚的中央玻璃按钮。先用这个组件确认，再将选定参数适配到 SwiftUI。

## 9 月 7 日第二轮反馈

- 工作为蓝灰，休息为薄荷绿；整个休息区保持可见，经过的部分再加深。色块的起点与工作杆共用角度，终点与休息杆共用角度，跨 12 点也一致。
- 移除 120 / 30 分钟上限。每圈仍为 60 分钟，可以连续拖到 3、4 小时或更长。完整圈数用逐层加深的底色表示，多圈阴影在表盘外平滑扩散；不会无限增大组件。精确时长在中央读数确认。
- 拖动时中央播放图标暂时变成 Work / Rest 和设定时长；松开、取消拖动或窗口失焦后立即恢复。悬停不弹浮层。键盘调整时按下显示、松开恢复。
- 运行／暂停修改仍保留已用时间与累计；休息中调整工作杆只修改下轮工作时长。

逻辑与几何检查：`node prototype/flat-dial/check.mjs`。本轮按用户偏好不接管浏览器，最终视觉与手感由用户刷新预览后确认。
