# Design experiments

Historical studies, kept as part of building in public. They are not the current
app and should not be installed alongside it.

- `flat-dial/`: interactive HTML dial and calendar reference, with sample data.
- `glass-study/`: native material and drag experiments.
- `native/`: earliest native prototype; records live only in memory.

The current app is in [`Sources/`](../Sources/) and built with
[`scripts/build.sh`](../scripts/build.sh). See the [current guide](../NATIVE.md).
