# 原生玻璃材质对照

> 当前交互以 `prototype/flat-dial/cycle-design.md` 为准：Work 保持 Rest 时长并携带外杆移动；Cycle 在零 Rest 时可回推 Work；两段均可为零，中央保留双读数。下方历史迭代规则已被替代。

独立 SwiftUI 组件研究，使用 macOS 26 的 `glassEffect(.regular, in: .circle)`。仅比较材质与拨杆手感，不替换原生计时应用，也不记录学习时间。

```sh
zsh prototype/glass-study/run.sh
```

左右为浅色／深色；顶部切换 Liquid Glass 与普通平面圆按钮，可选 1、50、60、120、180、240 分钟。两根拨杆可拖动，松开恢复中央读数。选择超过两小时的对照样本会关闭该样本的两小时限制。

中央播放图标只是布局示意；计时、暂停及台账规则请在 HTML 预览中试。此窗口没有通知、数据库或菜单栏常驻入口。关闭窗口或 Command-Q 退出。编译和运行产物位于独立临时目录，退出清理，不安装到 Applications。

比例：外盘半径 134、内盘半径 105.3（内盘面积约占外盘 61.8%）、中央按钮半径 51.2（外盘半径的约 38.2%）。比例用于约束尺寸，不表示美感已经获得数学验证。

已验证：本机 Swift 编译成功；独立窗口实际截图确认深浅色布局、系统玻璃和径向拨杆呈现。原生拖动手感仍待用户确认，不据此宣称完整原生计时应用完成。

拖动规则已与 HTML 同步：中央按钮以内不响应；按住拨杆后可在任意更远半径操作；到达上下限后，需要鼠标方向重新与拨杆对齐才接回。`DialDrag.swift` 独立管理角度与边界状态。检查：`zsh prototype/glass-study/check.sh`，编译产物与缓存检查后清理。原生构建和拖动轨迹检查已通过，更新后的窗口已重新打开供用户试用。

最新联动：工作杆移动时休息终点固定，只在间隔缩至一分钟后推着休息杆前进。反向移动会增加休息长度；启用两小时限制时也遵守休息长度上限。原有固定休息时长的联动方式已替换，原生检查覆盖新规则。

最新调整替代前述中央无效区：按钮范围内可以继续拖动，只在靠近圆心时连续减小灵敏度。显示使用未取整角度，数字仍按分钟；抓取时端点略微放大并带局部光晕。默认移除外侧刻度。HTML 还提供径向参考线比较与松手过渡，原生材质窗口仍是独立实验，不代表完整产品已迁移。

最新布局同步为外侧 Cycle 长杆、内侧 Work 短杆，保持 Work 蓝灰与 Rest/Cycle 薄荷绿。外杆中央读数显示总周期，表盘下常驻 Work / Rest / Cycle 三项时长。外杆移动不改工作长度，内杆仍采用固定终点和一分钟推动规则。窗口已编译更新供试用。

最新外杆读数显示 Rest；当休息只剩一分钟、继续回拨推动 Work 缩短时，读数改为 Work，外杆采用工作色。向外恢复只调整休息。三项时长改成固定等宽列，标签在上、放大数值在下。
