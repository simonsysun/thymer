# Thymer Logo 设计文档

状态：已根据用户选图修订、独立评审并执行。构图概念通过设计师评审；生产稿未通过。目标是一个可讨论、可缩放的品牌标志；尚不替换安装图标。

## 1. 产品与识别目标

Thymer 是本地优先的 macOS 工作/休息计时器，支持拖动双指针设置周期、为任务命名，并回看当天时间记录。名字来自《卓有成效的管理者》的 “Know Thy Time”。它强调看清时间、掌握节奏，不强调催促、效率竞赛或 AI 魔法。

标志应先让人想到一件安静、准确的计时工具，再通过两种半径与双指针联想到真实操作界面。无需让图案独自讲完记录、日历和哲学。

当前交付：一个无文字的主标志概念、独立设计评审和执行记录。macOS 图标容器、单色菜单栏符号、字标与安装适配不在本轮自动完成范围。

## 2. 用户反馈与失败分析

- 原始操作页面是主要参考；配色和面积无需逐像素复制。
- 用户要求更扁平、更专业，Work、Rest 之间以及周围有留白。
- 第一轮完整厚圆环、突出白色中心、奶油色方形底座与投影共同产生甜甜圈观感。
- 第二轮改变为普通钟面，丢失了双半径的产品特征。
- 第三轮直接剪开圆环，蓝区、绿区、悬空指针失去统一中心与边界关系，显得零散。
- “黄金比例”仅可辅助大小关系，不能证明审美质量；禁止将未测量的生成图宣称为精确黄金比例。

## 3. 参考锁定

**主参考：实际 Thymer 圆盘**（Sources/TimerDial.swift，用户提供的操作截图）。

必须保留：共同圆心；较短的 Work 半径；较长的 Cycle 终点半径；蓝灰与薄荷绿的语义；两根细指针和小端点；安静的空白背景。

借用规则而非图案：

- Adobe《Minimalist logo design》：二维几何、删除装饰、同时设计正负形；缩小时不能变成难辨的细节。
  https://www.adobe.com/uk/creativecloud/design/discover/minimalist-logo-design.html
- Refero skill 的 icons craft：光学校正比机械居中更重要；统一线宽；以半尺寸、灰度和深浅背景验证。
- Refero 在线风格库本轮返回 NO_SUBSCRIPTION，未获得可用案例；不声称已经研究其具体品牌案例。使用上面的原产品参考、公开指南及随 skill 提供的 craft 规则。

| 决定 | 来源 | 用途与约束 |
|---|---|---|
| 双半径与共同圆心 | 原产品界面/源码 | 作为唯一识别特征，避免增加字母、杯子或普通钟面 |
| Work 蓝灰、Rest 薄荷绿 | 用户与现有界面 | 代表两类时间，不把颜色随意交换 |
| 无凸起、无渐变、无阴影 | 用户最新纠正 | 从几何和留白获取层次 |
| 留白作为尚未占用的圆盘区域 | 用户要求+Adobe | 不把它命名为新产品的“空闲阶段” |
| 小中心、完整关系 | 失败图反证 | 留白不能让任何指针悬空 |
| 光学校正与缩放验证 | Refero craft | 不用大尺寸图的精致感代替小尺寸可用性 |

## 4. 当前执行稿：用户选定的完整圆盘

最新用户选择优先于初次评审建议：保留图 exec-469c1350-a878-4c02-8619-fab12b1341c6.png 的完整圆盘、中心空白和双指针。用户明确要求蓝、绿、白各在圆环上占一段，不沿用截图的面积。

已撤回的提案（未执行）：0.15R 小枢纽、Rest 仅外轨的方案。原因：它偏离用户随后明确选定的基准。

| 元素 | 执行规则 |
|---|---|
| 角度 | 12点为0°，顺时针；起点285° |
| 蓝 Work | 204°，从285°跨越顶部到129°，约57% |
| 绿 Rest | 72°，从129°到201°，20% |
| 白色留白 | 84°，从201°到285°，约23%；在圆环左下方，不仅仅是中心 |
| 中心 | 空白圆，半径0.38R，无描边/投影/内容 |
| Work 指针 | 沿蓝绿边界129°，从0.38R到0.84R |
| Cycle 指针 | 沿绿白边界201°，从0.38R到R |
| 线与点 | 线宽0.026R，端点直径0.065R，圆端，共用圆心 |
| 颜色 | 蓝#93A6BE；绿#A1CABB；冷白#F7F9FC；指针#46566B/#2D8975 |
| 白区轮廓 | 仅允许极细冷灰外缘，不超过0.008R；保持完整，不剪成C形 |
| 画面 | 单标志、纯白底、标志直径约画布75%；无圆角方形卡片 |
| 材质 | 全平涂，无渐变、阴影、发光、浮雕、奶油色底座 |

构图是品牌抽象，不表示某个默认周期，也不宣称精确黄金比例。双手的长度差继承产品，不要求两类色块完全复刻实时绘制逻辑。

## 5. 执行与验收

1. 独立产品 Logo 设计师审阅；记录见 [logo-design-review.md](logo-design-review.md)。初稿 REVISE，用户选图后重新给出上述唯一参数。
2. 用内置 imagegen 按用户选图进行受控编辑。完整提示词保存于 logo-generation-prompt.txt；不把失败图继续当风格参考。
3. 主代理与同一设计师核对：蓝绿白三段是否明显；白区是否在圈上；是否完整、共心；指针是否贴边界；是否仍有渐变/立体；是否漂移成普通钟表。
4. 只针对具体偏差修订。生成结果是概念，不能把近似几何宣称为精确矢量稿；最终采用由用户决定。
5. 未通过的图明确标记，不作为已经验收的安装资产。无安装、发布或Git提交。

验收重点：保留用户认可的整体；蓝绿白三段清楚且连续；留白不造成零散；没有悬空指针或凸起中心。32px/64px的实际缩小检查若未进行，明确保留为后续适配工作，不虚报通过。

## 7. 可编辑 SVG 阶段

按用户授权安装并使用 Inkscape 后，已完成 [SVG 主稿与预览](vector/README.md)。几何由数值直接构造，在 Inkscape 中打开检查，使用 Inkscape 后台导出。用户随后明确采用直接 SVG 编辑与后台渲染，避免抢占焦点。

主稿包含精确的 204°/72°/84° 色区、共同圆心、规定半径和纯色；没有渐变、滤镜或嵌入位图。独立设计师看过 512、64、32 像素图后通过主稿构造，指出原版直接缩至32像素时指针太细。

据此增加32/64像素光学版本，仅将指针线宽设为输出1.5像素、端点直径3像素。再次独立目视复核通过，作为小尺寸彩色概念供用户比较。正式品牌采用、菜单栏单色适配、应用图标封装和安装仍未执行。
